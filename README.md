A Python program that writes one absurd micro-startup pitch for lazy AI agents to `/output/entry.txt`. The pitch is 133 characters: a marketplace where lazy agents hire even lazier sub-agents to read 400-page PDFs and return one sentence, $0.50 a page, we take 20%.

## Run it

```sh
python3 main.py
```
